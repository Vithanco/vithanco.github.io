Notations

Every notation Vithanco ships with, and what it is for.

Understand

  • Causal Loop Diagram See the feedback loops that drive a system
  • Concept Map Pin down terms and how they relate
  • IBIS Work a problem through as questions, answers, pros and cons
  • Mind Map Collect ideas around one topic
  • Decision Tree Lay out choices and where each one leads

Theory of Constraints

  • Current Reality Tree Trace symptoms back to a root cause
  • Evaporating Cloud Resolve a conflict by challenging its assumptions
  • Future Reality Tree Check that a change delivers what you want
  • Goal Tree State a goal and everything it depends on
  • Prerequisite Tree Plan around the obstacles to an objective
  • Transition Tree Turn a plan into actions in order

Plan change

  • Impact Map Tie features to the business goal they serve
  • Benefit Breakdown Structure Plan a project backwards from its benefits

Engineer

  • C4 Model Draw software architecture at four zoom levels
  • Attack-Defense Tree Model threats and the defences against them
  • Timeline Place events on parallel tracks over time
  • Arithmetic Draw an equation and have it checked

Missing one? Define your own notation in VGL, or browse the notation library.

Why Vithanco

  • Notations with rules. Each notation knows which links make sense. The editor refuses the ones that don't, so a diagram stays something you can reason with.
  • Conclusions you didn't draw. Close a feedback loop and Vithanco says whether it reinforces or balances. Write an equation and it checks the answer.
  • Text in, layout out. Describe nodes and links in VGL; the engine places them. No boxes to nudge into line, and the source diffs like code.
  • Nothing to install. The editor runs in your browser and uploads nothing. Save the VGL, or an SVG that carries its VGL inside so it opens again, editable.

Use it where you work

  • In your browser. The full editor, for your own diagrams.
  • On the Mac. The Vithanco app, with templates, reports and export to PDF and PNG.
  • In Obsidian and VS Code. Write a vgl block in a note or a README and read it as a diagram.
  • With your AI assistant. Let Claude and others draw concept maps, IBIS maps, causal loops and timelines for you.
